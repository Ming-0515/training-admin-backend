服务暂时不可用

nginx 无法连接到后端服务（http://localhost:8080）。

最常见的原因是后端没有启动，请按顺序排查：

  • 后端是否已启动：netstat -ano | findstr :8080
  • 启动命令：在 training-admin-backend 目录执行 mvn spring-boot:run
  • 看后端控制台是否有报错（端口占用 / 数据库连不上）
  • 确认 MySQL 已启动，且 training_admin 库已初始化

此页面由 nginx 的 error_page 500 502 503 504 /50x.html 提供。 没有它的话，后端未启动会被 nginx 报成 404，很难定位。
